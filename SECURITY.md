# Security

TuiLens launches commands with the permissions of the local user. The local IPC token is not a sandbox.
Recordings, screenshots and scenario reports may contain terminal content. Do not attach secrets or private recordings to public issues.

For a vulnerability, use GitHub private vulnerability reporting when available. Otherwise, open an issue requesting a private reporting channel without exploit details or sensitive data.

# 安全

TuiLens 使用本机用户权限启动程序，本地 IPC 令牌不提供沙箱隔离。
录制、截图和报告可能包含终端正文，不要向公开 Issue 附加秘密或私有录制。
漏洞优先通过 GitHub 私密漏洞报告提交；不可用时可公开请求私密联系渠道，不附利用细节或敏感数据。
