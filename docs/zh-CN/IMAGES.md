# 图片与区域截图

[English](../IMAGES.md) · [简体中文](IMAGES.md)

启动参数 `images` 可设为 `off`、`sixel` 或 `all`，默认 `off`。

| 配置 | 启用能力 |
| --- | --- |
| off | 文字与字符块 |
| sixel | SIXEL |
| all | SIXEL 与下述 Kitty 子集 |

浏览器仅加载所需组件，不声明未启用的能力。SIXEL 模式通过 DA1 属性 `4`
报告支持；字符像素尺寸由实际终端画布计算。Kitty 子集支持内联数据查询
`a=q`，不伪装终端品牌或版本。

## SIXEL

使用 `@xterm/addon-image 0.9.0`。启用时先等待公开图像查询确认解码器就绪，
避免首张图像在异步初始化期间丢失。每次写入等待解析完成，截图再等待字体、
终端绘制与浏览器合成。

- 支持图像数据、调色板、字符尺寸报告和终端擦除。
- 图像上限 4M 像素，单序列上限 8 MiB，缓存上限 32 MiB。
- IIP 未启用。图片滚动与文字覆盖采用插件的字符格机制。
- 不保证每种终端的 SIXEL 光标策略一致；应以具体控制序列和截图验证。

## Kitty 子集

本实现使用浏览器图像解码和独立绘制层，支持：

- `t=d` 内联数据，`f=100` PNG、`f=24` RGB、`f=32` RGBA。
- `a=t` 传输、`a=T` 传输并放置、`a=p` 放置、`a=q` 查询。
- `m=1/0` 分块传输，跨输入块的 APC 前缀和结束符。
- 显式图像 ID；替换已有图像、`d=i/I/a/A` 删除位置或图像。
- `q=0/1/2` 响应控制。
- 普通放置的字符矩形与 `C=1` 保留光标。
- `U=1` 虚拟放置，前景色编码图像 ID；Unicode 占位符携带行列，
  可选第三个组合符编码图像 ID 高位。
- 虚拟放置随实际字符格滚动，正文覆盖占位符时遮挡对应图块。

虚拟放置只支持 `p=0`，图像保持纵横比。显示层隐藏私用占位符的缺字字形，
字符缓冲区仍保留原始占位符和组合符。

普通放置随行标记滚动；被实际内容变化覆盖的格会被作废，整屏擦除与行擦除
会清除对应图块。行擦除按 `EL 0/1/2` 的水平范围计算交集。
它不提供所有 Kitty 覆盖和合成语义：对同内容重写、其他复杂局部擦除或
特殊滚动区域，应使用虚拟放置或显式删除再放置。

不支持文件、共享内存、压缩、动画、裁剪、非零 z 层、相对放置、自动图像 ID
和非零虚拟 placement ID。不要将 `all` 理解为完整 Kitty 规范实现。

PNG 完整签名、分块边界、CRC 与结束块在浏览器解码前校验，APNG 明确拒绝。
每张图像最多 4M 像素、边长不超过 4096；缓存上限 32 MiB、128 张图片，
最多 256 个放置。所有放置的声明面积累计最多 65536 格，视口之外的面积也
计入预算；超过预算时在分配逐格元数据前拒绝。元数据仅保存实际可访问的格子。
达到图片缓存上限时逐出最旧图像及其放置，已移出缓冲区的直接放置自动释放。
超大或不支持的请求按协议返回错误；`q=2` 请求不会收到响应。

## 区域截图

`observe` 的 `region` 使用从 0 起算的字符格坐标：

```json
{ "x": 2, "y": 1, "width": 10, "height": 4 }
```

区域必须完整位于当前终端内。根据实际字符像素度量裁剪，边缘向外取整，
返回的宽高来自实际 PNG。PNG 包含文字、SIXEL 和 Kitty 绘制层。
裁剪只影响截图，观察的字符状态仍可保留完整视口。

## 验证

`tests/images.test.ts` 使用独立生成的颜色图案验证原始像素：

- 协议启用与能力声明。
- 首图、更新、删除、查询与资源限制。
- Kitty 分块和虚拟放置、文字遮挡、滚动、resize、清屏。
- 字符格区域截图的尺寸与越界拒绝。

这些测试不代替目标终端宿主的全协议兼容性验证。
